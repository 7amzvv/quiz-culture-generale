# Quiz de culture générale

Un quiz web de cinq questions à choix multiple. L’interface est en français. Les questions sont en français par défaut et l’anglais est disponible.

## Lancer le quiz

1. Téléchargez ou clonez ce dépôt.
2. Ouvrez `index.html` dans un navigateur avec une connexion Internet.
3. Choisissez la langue des questions et une catégorie, puis cliquez sur **Commencer**.

Le projet utilise HTML, CSS et JavaScript. Il fonctionne directement dans le navigateur, sans installation ni clé API.

## Règles

- Une partie contient **5 questions** avec quatre réponses mélangées.
- Vous avez **10 secondes** par question. Vous pouvez modifier votre choix jusqu’au clic sur **Suivant** ou **Voir mon score**.
- Si le temps expire, la partie avance automatiquement. Une question ignorée rapporte zéro point, même si une réponse était sélectionnée.
- Le score est sur 5. Les corrections indiquent la bonne réponse et votre choix ou le temps écoulé. **Rejouer** revient au choix de catégorie.
